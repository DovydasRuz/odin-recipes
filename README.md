# Odin Recipes

A simple recipe website built as the first project in The Odin Project's Foundations course.

## Description

This project consists of:
- A homepage (`index.html`) listing all recipes
- Multiple recipe pages, each containing:
  - A title
  - An image
  - A description
  - An ingredients list
  - A step-by-step instructions list

## How to Run

Open `index.html` in a browser.
